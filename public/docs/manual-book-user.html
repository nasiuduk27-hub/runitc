1. Pendahuluan

Manual book ini digunakan sebagai panduan penggunaan RUN ITC Portal untuk user. Dokumen ini tidak membahas menu superadmin seperti System Access, Role, Permission, User Management, System Settings, System Health, dan Audit Log admin.

Menu yang muncul dapat berbeda antar user tergantung role dan akses yang diberikan. Jika ada menu yang tidak tampil, hubungi admin internal untuk pengecekan akses.

2. Registrasi Akun

Registrasi digunakan untuk membuat akun baru sebelum user dapat masuk ke portal.

Langkah Penggunaan

  1. Buka halaman login RUN ITC Portal.
  2. Klik link registrasi atau buat akun baru.
  3. Pada step Account, isi Account ID, email, password, dan re-type password.
  4. Klik Next setelah semua data valid.
  5. Pada step Personal, isi nama lengkap, nama panggilan, tanggal lahir, jenis kelamin, dan nomor WhatsApp.
  6. Lengkapi data tambahan yang diminta sistem.
  7. Klik submit untuk menyelesaikan registrasi.

Gambar 2.2 - Halaman Registrasi Step Personal

3. Login

  1. Buka halaman login.
  2. Masukkan Account ID atau email.
  3. Masukkan password.
  4. Klik Login.
  5. Jika data benar dan akun aktif, sistem akan membuka Dashboard User.
Gambar 3.1 - Halaman Login
Jika muncul pesan akun belum aktif, lakukan verifikasi sesuai instruksi sistem atau hubungi admin internal.

4. Dashboard User

Dashboard menampilkan ringkasan aktivitas user, shortcut menu, status operasional, dan notifikasi penting.

Komponen Umum

  • Sidebar menu untuk navigasi.
  • Header berisi profil dan notifikasi.
  • Widget ringkasan operasional sesuai akses user.
  • Informasi kelengkapan profile jika tersedia.
Gambar 4.1 - Dashboard User

5. Profile User

  1. Buka menu Profile.
  2. Periksa data pribadi yang tampil.
  3. Ubah data yang perlu diperbarui.
  4. Upload atau ganti foto profile bila diperlukan.
  5. Simpan perubahan.

Perubahan Password

  1. Buka bagian ubah password.
  2. Masukkan password lama dan password baru.
  3. Konfirmasi password baru.
  4. Simpan perubahan.
Gambar 5.1 - Halaman Profile User

6. Notifikasi

  1. Klik icon notifikasi pada header.
  2. Baca daftar notifikasi terbaru.
  3. Klik salah satu notifikasi untuk membuka detail jika tersedia.
  4. Gunakan fitur tandai semua sudah dibaca jika diperlukan.
Gambar 6.1 - Dropdown Notifikasi
Gambar 6.2 - Halaman Daftar Notifikasi

7. SPV List

SPV List digunakan untuk melihat dan mengelola data supervisor sesuai hak akses user.

  1. Buka menu SPV List.
  2. Gunakan pencarian atau filter jika tersedia.
  3. Periksa nama SPV, status, dan informasi terkait.
  4. Untuk user dengan akses pengelolaan, tambahkan atau perbarui data SPV sesuai kebutuhan.
Gambar 7.1 - Halaman SPV List

8. Distribusi

Distribusi digunakan untuk membagi test/admin atau peserta ke SPV yang bertugas.

  1. Buka menu Distribusi atau Test Admin sesuai nama menu yang tampil.
  2. Pilih tanggal, nomor admin, atau client yang akan dikelola.
  3. Pilih SPV yang bertanggung jawab.
  4. Tentukan pembagian peserta atau batch.
  5. Simpan distribusi.
  6. Periksa ulang hasil distribusi pada tabel.
Gambar 8.1 - Halaman Distribusi
Gambar 8.2 - Form Pembagian SPV / Batch

9. Monitoring

Monitoring digunakan untuk melihat status test, peserta, dan aktivitas operasional secara realtime atau periodik.

  1. Buka menu Monitoring.
  2. Pilih filter tanggal, nomor admin, client, atau room jika tersedia.
  3. Periksa status peserta dan progress test.
  4. Gunakan informasi status untuk tindak lanjut operasional.
Gambar 9.1 - Halaman Monitoring

10. Collect CRC

Collect CRC digunakan untuk mengumpulkan atau memeriksa file CRC hasil pelaksanaan test.

  1. Buka menu Collect CRC atau menu CRC yang tersedia.
  2. Pilih nomor admin atau data test.
  3. Jalankan proses collect/generate sesuai tombol yang tersedia.
  4. Periksa status CRC yang berhasil terkumpul.
  5. Download atau upload file CRC jika diperlukan.
Gambar 10.1 - Halaman Collect CRC

11. Generate CRC / Generate Absen

Fitur ini digunakan untuk menghasilkan dokumen pendukung seperti file CRC atau absensi peserta.

  1. Buka menu Generate CRC atau Generate Absen.
  2. Pilih nomor admin/test yang sesuai.
  3. Klik tombol generate.
  4. Tunggu sampai sistem selesai memproses data.
  5. Download hasil generate jika tersedia.
Gambar 11.1 - Halaman Generate CRC / Generate Absen

12. Test Document

Test Document digunakan untuk mengelola dokumen test, issue peserta, CRC, BA Test, dokumen support, dan download folder admin.

Halaman Utama

Tabel Test Document menampilkan Nomor Admin, Klien, Keterangan, Tanggal, Issue, File, dan Aksi.

Gambar 12.1 - Halaman Test Document

Search dan Filter

  1. Gunakan kolom search untuk mencari nomor admin atau keterangan.
  2. Klik Filter untuk membuka filter lanjutan.
  3. Pilih rentang tanggal, nomor admin, atau nama klien/institusi.
  4. Klik Terapkan Filter.
  5. Klik Reset untuk menghapus filter aktif.
Gambar 12.2 - Filter Test Document

Input Data Filing

  1. Klik tombol Input Data.
  2. Pilih Nomor Admin.
  3. Sistem akan menampilkan Test Date, Klien/Institusi, dan daftar peserta.
  4. Isi Keterangan Umum jika diperlukan.
  5. Centang peserta yang memiliki issue atau perlu dicatat dalam berita acara.
  6. Isi catatan issue pada peserta yang dipilih.
  7. Klik Simpan Data.
Gambar 12.3 - Modal Input Data Filing
Gambar 12.4 - Daftar Peserta & Issue

Manage Files

  1. Pada baris Nomor Admin, klik Manage Files.
  2. Pilih kategori file.
  3. Pilih file dari perangkat.
  4. Isi nama file opsional jika diperlukan.
  5. Klik Upload.

13. Filing System

Filing System digunakan untuk menyimpan, mengelola, mengunduh, dan membagikan dokumen sesuai hak akses user.

  1. Buka menu Filing System.
  2. Gunakan pencarian atau filter untuk menemukan dokumen.
  3. Klik upload untuk menambahkan dokumen baru jika memiliki akses.
  4. Pilih file dan lengkapi metadata yang diperlukan.
  5. Gunakan download untuk mengambil file.
  6. Gunakan share atau permission jika tersedia dan diizinkan oleh role user.

14. FAQ / Troubleshooting

KendalaSolusi
Tidak bisa loginPastikan Account ID/email dan password benar. Jika tetap gagal, gunakan lupa password atau hubungi admin.
Akun belum aktifLakukan verifikasi sesuai instruksi sistem atau minta bantuan admin internal.
Menu tidak munculAkses menu tergantung role. Hubungi admin untuk pengecekan role user.
Upload file gagalPeriksa koneksi, ukuran file, format file, dan coba ulang. Jika masih gagal, laporkan ke tim teknis.
Data peserta belum munculPastikan nomor admin sudah benar dan peserta sudah memiliki status yang sesuai di sistem.
File tidak bisa didownloadPastikan file tersedia dan user memiliki hak akses download.
